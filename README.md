# Balloon-Pop-Bot-Embedded-Vision-Guided-Tracking-Robot
An embedded robotics platform integrating ROS with a lightweight YOLOv8 model deployed on an edge device for real-time vision tracking and motion control. Designed and integrated a servo-driven balloon-popping mechanism for autonomous tracking and actuation.
